# Ollama Health Check

A lightweight open-source Python tool for monitoring a local Ollama AI server.

## Features
- Check Ollama server availability
- Display Ollama version
- List installed AI models
- Detect connection errors
- No external Python dependencies

## Requirements
- Python 3.9+
- Ollama installed locally

## Usage
Run `python3 ollama_health.py` in your terminal.

## Privacy
Connects only to the local Ollama API at http://127.0.0.1:11434. No cloud services or API keys required.
